# LumaVale – Art Direction

## Purpose

This document defines the visual identity of LumaVale.

Every visual asset, UI component, animation, and environment should follow these guidelines to maintain a consistent player experience.

---

# Visual Style

LumaVale uses a cozy fantasy pixel art style.

The world should feel:

* Cozy
* Warm
* Peaceful
* Magical
* Alive
* Readable

The goal is not realism, but clarity and charm.

---

# Camera

* Perspective: Top-down
* Camera: Fixed follow camera
* No rotation
* No zoom during normal gameplay

---

# Resolution

Internal Resolution

480 × 270 pixels

Display Scale

3× or 4×

This provides a crisp pixel-art appearance while supporting modern displays.

---

# Tile Specifications

Tile Size

16 × 16 pixels

Future expansion may support 32 × 32 assets, but the MVP must use a single tile size consistently.

---

# Character Specifications

Player Sprite

16 × 24 pixels

Alternative

32 × 32 pixels

Animation

* 4 directions
* Idle
* Walk
* Attack
* Hurt
* Death (optional)

Frames

4–6 frames per animation

---

# Environment Style

Environment should include:

* Soft grass
* Dirt paths
* Wooden buildings
* Stone details
* Trees
* Bushes
* Flowers
* Small decorations

Avoid visual clutter.

Gameplay objects must remain easy to identify.

---

# Color Palette

Preferred palette

* Warm greens
* Natural browns
* Soft blues
* Gentle yellows
* Light gray stone
* Slight pastel tones

Avoid:

* Highly saturated neon colors
* Extremely dark environments
* Heavy black outlines
* Excessive visual contrast

---

# Lighting

Lighting should feel soft and natural.

Preferred effects

* Gentle sunlight
* Warm evening colors
* Soft shadows
* Slight ambient glow

The environment should remain readable during both day and night.

---

# User Interface

Style

Modern fantasy journal

Inspiration

* Adventure notebook
* Parchment
* Wooden frames
* Soft rounded panels

UI should be:

* Clean
* Readable
* Minimal
* Consistent

Avoid futuristic or sci-fi elements.

---

# Mood Board

Target emotional experience

* Cozy
* Magical
* Peaceful
* Curious
* Welcoming
* Slightly mysterious

Players should always feel safe inside the town while remaining curious about the world beyond.

---

# Visual Consistency Rules

Never mix:

* Pixel art with AI-generated semi-realistic images
* Different tile sizes within the same scene
* Isometric assets with top-down assets
* Sci-fi UI with fantasy environments
* Multiple color palettes without adjustment

Every asset should appear as though it belongs to the same world.

---

# Art Direction Checklist

Every new asset should satisfy the following:

* Matches the pixel-art style
* Uses the approved palette
* Fits the top-down perspective
* Matches the selected tile size
* Maintains visual readability
* Supports the cozy fantasy atmosphere

Assets that do not meet these requirements should not be included in the project.
