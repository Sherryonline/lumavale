# LumaVale – Visual Reference Guide

## Purpose

This document defines the visual references for LumaVale.

The references are used to communicate visual direction to developers,
artists, AI coding agents, and image-generation tools.

> These images are for inspiration only. Do not copy layouts, characters,
> compositions, sprites, or identifiable visual elements directly.

> Lấy cảm hứng, không sao chép.

---

# Core Visual Direction

LumaVale uses:

- Cozy fantasy pixel art
- Top-down perspective
- 16×16 tiles
- Warm and slightly pastel colors
- Soft lighting
- Clear silhouettes
- Minimal black outlines
- Modern fantasy journal UI

The visual mood should feel:

- Cozy
- Magical
- Alive
- Warm
- Peaceful
- Slightly mysterious
- Easy to read

# Approved Visual Rules

AI coding agents and image-generation tools must follow these rules:

1. Use top-down cozy fantasy pixel art.
2. Use a consistent 16×16 tile grid.
3. Use warm, natural, slightly pastel colors.
4. Keep interactive elements easy to identify.
5. Avoid strong black outlines.
6. Avoid excessive visual noise.
7. Keep lighting soft and readable.
8. Use fantasy journal-style UI.
9. Do not combine incompatible asset styles.
10. Do not reproduce any reference image directly.

---

# Prohibited Visual Mixing

Do not combine:

- Pixel art and semi-realistic AI art
- 16×16 environments and 64×64 character sprites
- Top-down and isometric perspectives
- Fantasy world art and science-fiction UI
- Assets from multiple artists without palette normalization
- Highly detailed sprites with very simple environments

---

# Reference Usage Rule

Each reference should answer one specific question.

Examples:

- How should the Town Square be organized?
- How dense should the forest appear?
- How should resources stand out?
- How large should NPCs appear?
- How should the inventory be structured?
- How should day and night differ?
- Which colors define the LumaVale mood?

References must not be treated as instructions to reproduce another artist's work.

> Inspiration only. Do not copy.
